# STEP6

## プロンプト

600ミリ秒で90度回転するようになりました。このロボットで迷路を脱出するアルゴリズムを実装してください。

## 回答

承知いたしました。現在のロボットの動作設定（直進2000ms、右回転600ms）を維持しつつ、迷路脱出アルゴリズムを実装します。

ロボットのセンサー（HC-SR04）は前方を向いているため、最もシンプルで効果的なアルゴリズムである**右手法（Right-Hand Rule, 常に右側の壁に沿って進む方法）**を実装します。

### 🤖 迷路脱出アルゴリズム：右手法

右手法のロジックは以下の通りです。

  1. 右側に壁があるか？
     * ある: 前に進めるなら直進し、壁に突き当たるなら左に曲がる。
     * ない: 右に曲がる。
    
     HC-SR04センサーは前方の距離しか測れないため、「右側に壁があるか」を直接判断できません。そこで、このロボットの制約に合わせてロジックを修正し、**「前方に壁があるか」**を主軸に判断します。
    
     修正された判断ロジック（前壁検知ベース）
    
      1. 直進可能か？
         * センサーで測定した距離が閾値（例: $15 \text{cm}$）より遠い場合:
          * 前進する（$2000 \text{ms}$）。
          * センサーで測定した距離が閾値より近い場合（壁が迫っている）:
          * 右手法に基づき、右側に進路を探すため右回転する（$600 \text{ms}$）。
        
        このシンプルなルールは、T字路や角で必ず右回転を試みるため、壁伝いに進む動作となります。
        
### 💻 迷路脱出アルゴリズムの実装

以前のコードの直進・回転の値を活かしつつ、dest() 関数を復活させ、loop() 関数をアルゴリズムに置き換えます。

  1. グローバル定数と変数の追加距離測定の閾値と動作の時間を設定します。
  
     ```cpp
     // 新しい定数
     const float WALL_THRESHOLD_CM = 15.0; // 15cmより近ければ壁と判断
     // 既存の定数
     const int ROTATE_90_DELAY = 600; 
     const int FORWARD_DELAY = 2000;
     ```

  1. loop() 関数の実装
  
      loop() 関数を、距離測定と行動決定のロジックで書き換えます。
  
      ```cpp
      void loop()
      {
        // 1. 前方の距離を測定
        float distance = dest(); 
  
        // 2. 状態をクリア
        STOP(); 
        delay(100); 

        if (distance > WALL_THRESHOLD_CM) {
          // 【前方に壁なし】 直進する
    
          // 画面表示用に状態を一時的に設定
          current_movement = "MAZE: FORWARD"; 
          // 実際に直進
          FWD(); 
          delay(FORWARD_DELAY); // 2000ms 直進
        } else {
          // 【前方に壁あり】 右手法に従い右回転を試みる
    
          // 画面表示用に状態を一時的に設定
          current_movement = "MAZE: TURN RIGHT"; 
          // 実際に右回転
          RTR(); 
          delay(ROTATE_90_DELAY); // 600ms 右回転
        }
  
        // 動作を終えたら一時停止
        STOP();
        delay(300); // 動作間のクールダウン
      }
      ```

  1. flip() 関数の修正
  
      OLEDに距離も表示するように距離表示のコメントアウトを解除します。
