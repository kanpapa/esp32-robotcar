# STEP8

## プロンプト

回転動作の際に、ほぼ180度回転して後ろに戻ってしまいます。修正してください。

## 回答

ご報告ありがとうございます。回転時間が長すぎるため、90度ではなく約180度回転してしまっている状態ですね。

以前のコードで設定した600ミリ秒が、実際のロボットにとっては180度に近い回転時間だったようです。

90度回転させるために、設定されている回転時間 (ROTATE_90_DELAY) を半分の300ミリ秒に修正します。

### 💻 修正後のプログラム（回転時間の変更）
以下の通り、定数設定部分のみを修正しました。他のアルゴリズムロジックに変更はありません。

### 調整について

回転時間の設定を300ミリ秒に変更しました。これで90度回転に近づくはずですが、もしまだ調整が必要な場合は、ROTATE_90_DELAY の値を微調整してください（例: 280msや320msなど）。
