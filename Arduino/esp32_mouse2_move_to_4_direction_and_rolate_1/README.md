# STEP1

## プロンプト
ロボットがどの動きをしているのかわかるようにOLEDに英語で表示するようプログラムを修正してください。

## 回答

ご要望に基づき、ロボットが現在行っている動きを英語でOLEDディスプレイに表示するようにプログラムを修正しました。

### 修正のポイント

グローバル変数 current_movement の追加: ロボットの状態（動き）を保持するための変数を定義しました。

モーター制御関数の修正: 各動作関数（FWD(), BAK()など）が実行される際に、current_movementに該当する動作名（例: "FORWARD"）を格納するようにしました。

flip() 関数の修正: 距離表示に加えて、current_movementに格納された動作ステータスをディスプレイの下部に表示するようにしました。
