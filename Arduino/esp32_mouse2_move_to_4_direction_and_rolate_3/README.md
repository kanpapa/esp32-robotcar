# STEP3

## プロンプト

今の状態はいろいろな動きをするようにしていますが、これを一旦コメントアウトしておいて、右方向に90度を４回曲がるプログラム修正してください。

## 回答

承知いたしました。現在の連続的な動き（ZIGZAGパターン）をコメントアウトし、代わりに**「右に90度回転する動作」を4回繰り返す**プログラムに修正します。

「右に90度回転」は、既存の**RTR() (Rotate to Right)** 関数を一定時間実行することで実現します。回転角度の調整は、delay() の時間で行います。

ここでは、**RTR() 動作を90度回転させるための時間を1000ミリ秒（1秒）**として仮設定し、それを4回繰り返すように修正します。

### 動作の調整について

const int ROTATE_90_DELAY = 1000; の値が、実際にロボットが90度回転するために必要な時間です。

  * 1000ミリ秒はあくまで仮の値です。
  * モーターの性能、電源電圧、タイヤの摩擦などによって、正確に90度回転する時間は異なります。
  * この値を変更し、ロボットが実際に90度回転する最適な時間を見つけてください。

これで、ロボットは起動後に右に90度回転し、停止という動作を計4回繰り返します。
