# STEP2

## プロンプト

距離表示を一旦コメントにしておいて、動きの表示を最大限大きな文字で表示するようにしてください。動作時間は1000ミリ秒のところをすべて5000ミリ秒にしてください。

## 回答

承知いたしました。以下の修正を行います。

距離表示のコメントアウト: flip() 関数内の距離測定と表示に関するコードをすべてコメントアウトします。

動作表示の最大化: flip() 関数内で、動作ステータスを表示する文字サイズを最大（display.setTextSize(4) 程度）にし、画面の中央付近に表示します。

動作時間の変更: loop() 関数内のすべての delay(1000) を delay(5000) に変更します。

### 変更点の概要箇所

|元のコード|修正後のコード|変更理由|
|---|---|---|
|loop() 内の delay()|delay(1000)|delay(5000)|動作時間を5秒に延長|
|flip() 内の距離測定|cm = dest(); など|コメントアウト|距離表示を一時的に無効化|
|flip() 内の表示|display.setTextSize(1); display.setCursor(0, 52);|display.setTextSize(3); 中央揃え計算|動作表示を最大限大きな文字で中央に表示|

これで、ロボットは各動作を5秒間続け、その間OLED画面には現在の動作ステータスが大きな文字で表示され続けます。
