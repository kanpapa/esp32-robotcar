# Program Revision History

このリポジトリのArduinoスケッチは、以下の順序で機能追加・修正を行いました。

| Ver | 変更概要 | 技術的な変更点 |
| :--- | :--- | :--- |
| **00** | **初期バージョン** | ・ZIGZAG動作（前後左右・回転）<br>・距離測定とプログレスバー表示 |
| **01** | **動作ステータスの英語表示化** | ・OLEDに現在の動作（"FORWARD", "TURN LEFT"など）を表示するように変更<br>・グローバル変数 `current_movement` の導入 |
| **02** | **表示の最大化と動作確認モード** | ・動作時間を1秒→5秒に変更<br>・距離表示を一時停止し、動作ステータスを最大フォントで画面中央に表示 |
| **03** | **90度回転テスト** | ・ZIGZAG動作を廃止<br>・「右に90度回転（仮設定1000ms）」を4回繰り返すループに変更 |
| **04** | **四角形描画 (テスト1)** | ・直進(1000ms) ＋ 右回転(400ms) を繰り返して四角形を描く動作に変更<br>・回転時間を短縮して調整 |
| **05** | **四角形描画 (テスト2)** | ・直進(2000ms) ＋ 右回転(600ms) に時間を変更<br>・動作確認用の調整バージョン |
| **06** | **迷路脱出 (右手法・ブロッキング)** | ・壁検知ロジックの実装（15cm以下なら右回転、それ以外は直進）<br>・`delay()`を使用した実装のため、直進中の衝突検知は不可 |
| **07** | **迷路脱出 (非ブロッキング制御)** | ・**大幅な構造変更**<br>・`delay()`を廃止し、`millis()`とステートマシンを導入<br>・移動中も常時距離測定を行い、即座に壁回避が可能に |
| **08** | **回転精度の最終調整 (完成版)** | ・回転時間を600ms→**300ms**に修正<br>・過剰な回転（180度）を防ぎ、適切な90度回転に調整<br>・距離表示機能の復帰 |

---
**補足:**
* **Ver 07以降**が、より実践的で安全なロボット制御コード（非ブロッキング処理）になっています。
* 実際の迷路探索には **Ver 08** のコードを使用してください。
