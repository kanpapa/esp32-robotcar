# 🛠 開発ログ: ESP32ミニカー　迷路脱出アルゴリズムの実装

**日付:** 2025/11/30

**トピック:** 右手法による迷路脱出アルゴリズムの実装と非ブロッキング制御

## 📝 概要
本日は、XIAO ESP32C6搭載ロボットにおいて、基本的な移動テストから「迷路脱出アルゴリズム（右手法）」の実装へと移行しました。
最大の変更点は、`delay()`を使用したブロッキング制御から、`millis()`とステートマシンを使用した**非ブロッキング制御**への移行です。これにより、移動中の継続的な衝突検知が可能になりました。

## 🚀 主な変更点

### 1. UIと視覚化 (OLED表示の刷新)
デバッグ効率を向上させるため、OLEDの表示レイアウトを変更しました。
* **変更前**: 距離のプログレスバー表示のみ。
* **変更後**: 現在の動作ステータス（例: `MAZE: FORWARD`, `MAZE: TURN RIGHT`）を**英語かつ最大フォントサイズ**で画面中央に表示。距離数値は画面上部に配置。

### 2. 動作精度の調整
90度旋回を正確に行うためのキャリブレーションを実施しました。
* **直進時間**: `2000ms` に設定。
* **回転時間**: 当初 `600ms` でテストしたが約180度回転してしまったため、**`300ms`** に修正し、およそ90度の右回転を実現。

### 3. アルゴリズム: 右手法の実装
HC-SR04超音波センサー（前方固定）を用いた簡易的な右手法アルゴリズムを実装しました。
* **壁検知の閾値**: `15.0 cm`
* **ロジック**:
    * **壁なし (> 15cm)**: 直進 (`FWD`)
    * **壁あり (<= 15cm)**: 右回転 (`RTR`) して回避行動をとる

### 4. アーキテクチャ: 非ブロッキング衝突検知
移動中にセンサー測定が止まってしまう問題を解決するため、コード構造を根本的に変更しました。

* **課題**: `delay(2000)` で直進中、センサー測定が行われず壁に衝突するリスクがあった。
* **解決策**:
    * `delay()` 関数を全廃。
    * `enum RobotState` を導入し、ステートマシンによる管理へ移行。
    * `millis()` を使用して経過時間を計測。
* **成果**: 直進動作中であっても約10msごとに距離測定が行われ、壁を検知した瞬間に即座に停止・回避行動へ移行可能になった。
